Regeln:
- engine.curve: Volllast-Drehmoment [U/min, Nm], aufsteigend, bis knapp über limitRpm.
  Leistung (kW) = Nm × U/min / 9549. Turbo: turboTau [0.3, 0.08]; Saugmotor: [0.02, 0.01].
- gearbox.ratios: Gangübersetzungen (Achse 4,0 kommt dazu). Höchstgeschwindigkeit
  ≈ limitRpm × 0,1047 × rR / (letzter Gang × 4,0) in m/s – soll 300–360 km/h ergeben.
- ers: { maxKW: 0 } = kein Hybrid; Hybrid z. B. { maxKW: 120, battMJ: 4, lapDeployMJ: 4, maxCrankNm: 200 }.
- aero.mode: 'none' (fest), 'drs' (Heckflügel öffnet in Zonen; dann zusätzlich
  straightFW: 1, straightRW: 0.5, cdStraightFW: 1, cdStraightRW: 0.42) oder 'active' (wie 2026).
- Werte realistisch halten: Masse 500–900 kg, Abtrieb gesamt 1.5–5 m², muScale 0.8–1.1.
- Keine echten Hersteller- oder Typnamen.

Regeln für model (das Aussehen – optional, reine Zahlen):
- Koordinaten in Metern vom Schwerpunkt: z vorne NEGATIV (Nasenspitze ≈ -2.7,
  Heck ≈ +2.0), x rechts positiv, y oben positiv (Boden ≈ -0.25, Helm ≈ +0.5).
  Das Modell ist für 3,40 m Radstand gezeichnet und wird auf spec.wheelbase gestreckt.
- Querschnitt { z, w, h, y, n, x }: w Breite, h Höhe, y Mitte, n Eckigkeit
  (2 = rund, 3 = abgerundet, 4–6 = kastig), x seitlicher Versatz. In jeder
  Liste z streng aufsteigend (von vorne nach hinten), mindestens 2 Einträge.
- Bauteile: nose, cockpit, engineCover, airbox ([] = entfernen), sidepod (nur
  die rechte Seite, [] = entfernen), floor [[x, z], ...], frontWing/rearWing
  { span, chord, thick, camber, y, z, flaps }, look { nose: 'low'|'mid'|'high',
  fin, beam, barge, grooves, diffuser, frontWing: false, rearWing: false }.
- parts (bis 80): loft { sections }, box { size, pos, rot, r }, wing { span,
  chord, pos, rotX }, cyl { r | r1+r2, len, pos, rot } (steht senkrecht, rot
  [90,0,0] = längs), sphere { r, pos, scale }. rot in Grad. mat: paint, team,
  team2, carbon, dark, chrome, glass. mirror: true spiegelt auf die linke Seite.
- Die Nase muss bei z ≈ -0.82 an das Cockpit anschließen (gleiche w/h/y wie
  der erste Cockpit-Querschnitt), sonst entsteht eine Lücke.
- Räder, Aufhängung, Lenkrad, Helm und Spiegel setzt das Spiel selbst.
